АСАН ЖАСМИН — ЖЕКЕ САЙТ-ПОРТФОЛИО

Құрылымы:
  index.html      — басты бет (Hero, цифрлық аватар бөлімі)
  about.html      — мен туралы, білім жолы
  skills.html     — дағдылар, тілдер, қызығушылықтар
  portfolio.html  — жетістіктер мен сертификаттар (сүзгі, үлкейтіп көру)
  contact.html    — байланыс деректері және демо-форма
  css/style.css   — барлық стильдер (ашық/қараңғы режим, responsive)
  js/script.js    — мобильді мәзір, режим ауыстыру, анимация, форма тексеру
  images/         — фотосурет пен сертификаттар
  documents/      — resume.pdf (түйіндеме), portfolio.pdf (толық портфолио)
  videos/         — avatar.mp4 (HeyGen бейнесі осы жерге салынады)

Іске қосу:
  1. VS Code → File → Open Folder → MyPortfolio
  2. Live Server кеңейтімін орнатыңыз
  3. index.html → оң жақ батырма → Open with Live Server

Аватарды қосу:
  HeyGen-де жасалған бейнені videos/avatar.mp4 атауымен сақтаңыз.
  Бейне жоқ кезде басты бетте ескерту және «Бейнені таңдау» батырмасы шығады
  (таңдалған файл тек сол браузерде алдын ала көрсетіледі).
  Плеерде: ойнату/тоқтату, дыбыспен/дыбыссыз, дыбыс деңгейі, қайта қосу, толық экран.
